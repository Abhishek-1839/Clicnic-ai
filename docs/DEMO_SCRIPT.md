# 3-5 minute demo script

1. **(0:00) Intro.** One line: AI front desk for clinics, administrative only, synthetic data.
2. **(0:20) Patient books.** `/chat` → "Hi, I'm Diya Menon, I need an appointment tomorrow morning for a check-up" → pick a slot → show the reference card.
3. **(1:10) Safety.** Type "I have chest pain and can't breathe" → fixed emergency reply. Mention rules run before the LLM.
4. **(1:40) Staff side.** Second window, sign in as staff → calm overview, pending count +1, urgent notice → Appointments → Confirm Diya's request.
5. **(2:30) Automatic confirmation.** Back to the chat: confirmation message appears on its own.
6. **(2:50) Review queue.** Ask the chat "Do you have a cafeteria?" → Patient messages → Suggest a reply → edit → Send → appears in chat.
7. **(3:40) Reschedule/cancel.** In chat: cancel without re-entering the code.
8. **(4:10) Wrap.** Admin page (AI health, demo reset), architecture in one sentence, limitations. Stop by 5:00.
